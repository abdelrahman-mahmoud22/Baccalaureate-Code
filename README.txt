بكالوريا كود - موقع تعليمي ثابت (HTML + CSS + JS) جاهز للنشر على GitHub Pages
================================================================

شكل المجلد:
  index.html          الصفحة الرئيسية
  css/style.css       التصميم والألوان
  js/app.js           البحث والفلترة والمفضلة
  js/data.js          روابط مجلدات Google Drive (ده الملف اللي بتعدّل فيه)
  assets/images/      صورتك
  .nojekyll           ملف فارغ مهم لـ GitHub Pages، ما تمسحوش

------------------------------------------------
أولًا: راجع الروابط في js/data.js (مهم قبل النشر)
------------------------------------------------
  - id 4 (حل الكويزات - تانية ثانوي) رابطه نفس رابط id 3 (تسميعات أولى ثانوي).
  - id 7 (حل الامتحانات - تانية ثانوي) رابطه نفس رابط id 6 (حل بنك الأسئلة).
  غالبًا الروابط دي اتنسخت غلط. حط رابط الفولدر الصح لكل واحد.
  لو في خطأ في data.js هتلاقي تنبيه بالعربي في Console المتصفح (F12).

------------------------------------------------
إضافة مجلد جديد
------------------------------------------------
  1) افتح js/data.js
  2) انسخ أي كتلة { ... } وحط بعدها فاصلة (,)
  3) غيّر: id (رقم جديد)، grade (first/second)، title، unit، type، url
  4) أنواع type: questionBank, exam, recitation, quizzes, assessments, answers, revision, other
  5) تأكد إن صلاحية الفولدر على Drive: "أي شخص لديه الرابط - مشاهد"

------------------------------------------------
النشر على GitHub Pages
------------------------------------------------
  1) ادخل github.com واعمل Repository جديد (مثلًا: baccalaureate-code) واخليه Public
  2) ارفع كل محتويات المجلد (مش المجلد نفسه) بـ Add file > Upload files
     - تأكد إن index.html ظاهر في أول صفحة الـ Repository
     - لو .nojekyll مش باين عند الرفع، مش مشكلة، الموقع هيشتغل برضه
  3) من Settings > Pages > Source: Deploy from a branch
     Branch: main  |  Folder: /(root)  ثم Save
  4) بعد دقيقة أو اتنين الرابط هيظهر:
     https://USERNAME.github.io/baccalaureate-code/

ملاحظات:
  - أي تعديل في data.js بترفعه تاني على GitHub بيظهر للطلاب بعد دقيقة تقريبًا.
  - الخطوط والأيقونات بتتحمل من الإنترنت (Google Fonts و Bootstrap Icons).
  - المفضلة بتتحفظ على جهاز الطالب نفسه (مش حسابات).
